# QikProp Chemical Descriptor Aggregation

## Overview

This workflow aggregates molecular descriptors generated by Schrödinger QikProp for compounds represented by multiple molecular structures. Multiple structures may arise from different protonation states, tautomers, stereoisomers, or conformations generated during compound preparation. To produce a single representative descriptor set for each compound, the workflow calculates the median value of each numerical QikProp descriptor across all associated structures.

The resulting aggregated descriptor set provides a single, robust representation for each compound that can be used for downstream cheminformatics analyses, machine learning, and virtual screening.

---

## Workflow

The workflow performs the following steps:

1. Reads the input dataset containing QikProp descriptors for one or more structures associated with each compound.
2. Groups structures belonging to the same parent compound.
3. Calculates the median value for every numerical QikProp descriptor within each compound group.
4. Produces a single aggregated descriptor profile for each compound.

Median aggregation reduces the influence of extreme values while preserving the central tendency of descriptor distributions.

## Requirements

- Python 3.10 or later
- pandas
- openpyxl

All required dependencies can also be installed using the repository-level `environment.yml`.

---

## Demonstration Data

The `demo` directory contains a small example illustrating the aggregation workflow.

### Input

**Median_calculation_input.csv**

Contains QikProp descriptors for multiple molecular structures associated with individual compounds.

### Output

**Median_calculation_output.xlsx**

Contains one aggregated descriptor profile per compound, where each numerical descriptor represents the median value calculated across all associated structures.

---

## Running the Workflow

Run the workflow from the command line:

```bash
python calculate_QikProp_median.py
```

Modify the input and output file paths within the script as required.

---

## Output

The workflow generates an Excel workbook containing one row per compound with median QikProp descriptor values suitable for downstream cheminformatics analyses, statistical modeling, and machine learning applications.
