# ODO Data Portal Code  

Python workflows supporting the curation, annotation, and processing of datasets used to construct the **Opioid Drug Ontology Data Portal (ODO-DP)**.

The repository contains the data curation and processing pipelines used to generate the ODO-DP dataset described in the accompanying publication. Workflows include manual curation from scientific literature, ChEMBL data retrieval and processing, compound annotation and molecular property generation from standardized chemical structures, and general dataset processing.


---

## 🚀 Quickstart  

Clone the repository and create the Conda environment.

```bash
git clone https://github.com/OpioidDrugOntology/odo-data-portal-code.git
cd odo-data-portal-code

conda env create -f environment.yml
conda activate odo-chem
```

Each workflow contains:

- Python scripts
- demonstration input files
- demonstration output files
- workflow-specific documentation

Refer to the README within each workflow directory for execution instructions.

# 🔬 Workflow Overview

## 1. Manual Curation Workflow

This workflow supports curation of bioactivity data extracted from scientific publications identified through PubMed.

Components include:

- Publication table extraction
- Assay description standardization
- ASCII normalization

**Result**

Publication-derived assay records suitable for integration into ODO-DP.

---

## 2. ChEMBL Curation Workflow

This workflow processes bioactivity data obtained from ChEMBL.

Components include:

- Retrieval of document metadata through the ChEMBL API
  - DOI
  - PubMed ID
  - Patent ID
- Reference prioritization
- Aggregation of redundant activity records using defined experimental matching criteria

**Result**

Curated ChEMBL-derived bioactivity records suitable for integration into ODO-DP.

---

## 3. Compound Processing Workflow

This workflow generates chemical identifiers, external database annotations, and calculated molecular properties from **canonical SMILES** generated by the upstream **chemical standardization workfloww**. Chemical standardization is performed prior to the workflows contained in this repository.

The compound annotation workflow includes:

- Generation of Standard InChI
- Generation of Standard InChIKey
- Retrieval of PubChem Compound IDs (CIDs)
- Retrieval of IUPAC names from PubChem
- Calculation of molecular formula
- Calculation of molecular weight
- Generation of additional molecular descriptors where applicable

**Result**

Compound records enriched with standardized chemical identifiers, external database annotations, and calculated molecular properties suitable for downstream integration into ODO-DP.

---

## 4. General Data Processing Workflow

- Generation of median QikProp descriptor values

**Result**

Median values for selected QikProp physicochemical descriptors (dipole, SASA, FISA, donorHB, accptHB, QPlogPw, QPlogPo/w, and QPlogS) calculated for each unique canonical SMILES.
